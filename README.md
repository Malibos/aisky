# AI SKY

Software house landing page — Apple VisionOS Spatial UI aesthetic.

## Stack
- Next.js (App Router) + Tailwind CSS + lucide-react
- Standalone `preview.html` for instant browser preview (no build)

## Files
- `app/page.tsx` — Next.js component (drop into an existing Next.js project)
- `preview.html` — self-contained HTML, open directly in a browser

## Preview
Open `preview.html` in any browser. Dark background, floating frosted-glass card, cyan neon CTA.
